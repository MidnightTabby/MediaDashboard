# 変更履歴 (Changelog - Japanese)

## [v0.03beta] - 2026-11-19 (Pre-release)

> **"MediaDashboard — 高速TSVメディア＆YouTube基準ダッシュボード"**  
> 溜め込んだ動画アーカイブを再生せずに一覧化し、「使わない素材の断捨離」と「再エンコード時のパラメーター確認・音量目安の把握」を一気に片付けるためのツールです。

### ✨ 主なアップデートと設計のポイント
- **実用重視の列順（左から右へ自然なワークフロー）**:
  - `ファイル基本情報` → `映像スペック・色空間` → `音声スペック` → `YouTube基準フラグ` → `音声診断（-AudioCheck時のみ右端）` の順に整理し、同じパラメーターでの再エンコードやスペック比較をしやすくしました。
- **撮影機材・音声ビットレートの追加と整理**:
  - `Duration` と `Container` の間に `Camera_model` を追加し、スマホやカメラの機種タグを取得。
  - `A_Codec` と `A_SampleRate` の間に `A_Bitrate_kbps` を追加（冗長で不確実になりやすい VBR/CBR 判定列は削除してシンプル化）。
- **ダブルクォーテーション（`""`）なしのクリーンなTSV出力**:
  - `Export-Csv` による自動クォートを廃止し、タブ区切りテキストを直接組み立てて UTF-8（BOM付き）で出力。スプレッドシートでもテキストエディタでも見やすい形式に統一しました（値内の改行・タブは安全にスペース置換）。
- **解像度ティア判定＆HDR検出**:
  - `8K` / `4K` / `1080p` / `HD` / `HD_CROPPED` / `SD` の自動分類と、`DolbyVision` / `HDR10` / `HLG` / `SDR` の判定を搭載。
- **音量診断オプション（`-AudioCheck`）**:
  - スマホ撮影動画に多い音量不足（`LOW_VOL`）や音割れ（`CLIP`）を `ffmpeg`（`volumedetect`）で検出し、編集前のゲイン調整や素材選別の判断材料を提供します。

### 📝 次期実装メモ（Roadmap）
- **`LOW_VOL` に対する目安ゲイン表示**: 編集ソフトでの初動を速くするため、目標ラインとの差分から目安となる補正量（例：`+12dB`）を `Peak_dB` の余裕度とあわせて提示するアイデア。
- **日付書式の柔軟化**: デフォルトのソート用書式を維持しつつ、US向け書式や Z世代のメモ感覚（`WED Sept 21 6p` のような直感表記）への切り替え検討。
- **クロスプラットフォーム展開**: 将来的な Go ヘルパー化や Chromebook / macOS 対応への布石。
